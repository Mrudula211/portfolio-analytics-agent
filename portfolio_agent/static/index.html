        How it works

        • Repeat questions come from an exact-match cache. Sector exposure for one named fund runs the calculator without the model.
        • Other questions cost one Gemini call that returns the whole plan. If a model is slow, the next one starts after 2.5 s.
        • Code formats every answer from query results, so the model never states a figure. Answers are graded against reference results, not SQL text.

        Full reports and the experiments behind these choices are in the repository's docs/ and reports/ folders.
